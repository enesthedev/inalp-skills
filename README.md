# inalp-skills

Agent skills for the İnalp Akademi project.

| Skill | What it does |
| --- | --- |
| `inalp-artifacts` | Rules for claude.ai Artifacts: brand look, language, Instagram carousels, developer specs, sharing. |

## Install

    npx skills add <github-user>/inalp-skills

or only this skill:

    npx skills add <github-user>/inalp-skills --skill inalp-artifacts

From a local clone:

    npx skills add ./inalp-skills
